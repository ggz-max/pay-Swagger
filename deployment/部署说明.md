## 构建环境变量

```bash
export PATH=/opt/node24/bin:$PATH
export COREPACK_NPM_REGISTRY=https://registry.npmmirror.com
export npm_config_registry=https://registry.npmmirror.com
export VITE_API_BASE_URL=/pay-swagger/api/v1
export VITE_PUBLIC_BASE=/pay-swagger/
corepack pnpm --filter @monetizelab/customer-web build
export VITE_PUBLIC_BASE=/pay-swagger/admin/
corepack pnpm --filter @monetizelab/admin-web build
corepack pnpm --filter @monetizelab/api build
```

## 数据库与进程

首次部署执行 Prisma `db push` 和 seed。后续发布只执行 `db push`，不得重复 seed，否则会清空演示交易数据。

PM2 配置为 `deployment/ecosystem.config.cjs`，进程名为 `pay-swagger-api`。Nginx 片段为 `deployment/nginx-pay-swagger.conf`，由现有 IP 站点配置 include。

## 发布命令

首次部署会重建演示数据，只允许在全新环境执行：

```bash
cd /var/www/pay-swagger
bash deployment/deploy-server.sh --first-deploy
```

后续发布不会执行 seed：

```bash
cd /var/www/pay-swagger
git pull --ff-only
bash deployment/deploy-server.sh
```

本地线上验收：

```powershell
node deployment/verify-deployment.mjs
```

脚本检查用户端、运营台和移动端的 HTTP 状态、页面主标题、控制台错误和失败请求，并把截图保存到 `产出/部署截图/`。
