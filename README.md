# MonetizeLab 商业化闭环沙盘

这是一个面向“用户产品经理-商业化方向”岗位的入职预演项目。

项目不是为了把候选人包装成资深研发或资深支付产品经理，而是通过一套可运行的小闭环，训练并证明以下能力：

1. 把复杂商业化业务拆成用户、认证、商品、订单、支付、权益、退款、对账和数据模块。
2. 写出研发可以评审、开发和验收的 PRD。
3. 理解核心业务规则如何落到接口、状态机、数据表、异步任务和测试用例。
4. 能围绕异常边界、产品取舍和验收标准与研发无障碍沟通。
5. 在面试中诚实地把项目表述为“基于 JD 完成的入职预演”，而不是虚构工作经历。

## 代码工作区

```text
apps/
├─ api/             NestJS API、Prisma SQLite、支付模拟器和后台任务
├─ customer-web/    React C 端购买与权益体验
└─ admin-web/       React 运营、客服和交易观察台
packages/
└─ contracts/       前后端共享状态、类型和展示映射
tests/
└─ e2e/             Playwright 端到端验证
```

## 本地启动

环境：Node.js 22+、pnpm 11+。当前机器使用 Codex 随附的 Node.js 24 与 pnpm 11。

首次运行：

```powershell
pnpm install
pnpm db:generate
pnpm db:push
pnpm db:seed
pnpm dev
```

本地地址：

- 用户端：http://127.0.0.1:5175
- 运营台：http://127.0.0.1:5174
- API：http://127.0.0.1:3000/api/v1
- Swagger：http://127.0.0.1:3000/docs

验证命令：

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```

演示数据清空可以在用户端点“重置演示”，完整恢复基础数据使用 `pnpm db:seed`。项目只使用本地支付模拟器，不接触真实资金与真实密钥。
